# U.Psy — Handoff Pack

Everything an external agent (Claude Code) or engineer needs to take full
ownership of the U.Psy platform in a new GitHub repository, with no Lovable
dependency and no re-discovery pass.

Copy this whole folder into the new repository as its `docs/` seed, and move
`CLAUDE.md` to the repository root.

## Machine-readable inventories

Under [`inventory/`](./inventory), generated by reading the repository:

- `routes.json` — 172 routes: file, route id, SSR mode, auth guard, head metadata.
- `edge-functions.json` — 33 functions: secrets read, cron/webhook nature, service-role use.
- `env.json` — 33 environment variables: access pattern, client visibility, call sites.
- `migrations.json` — 106 migrations: tables created, RLS/GRANT/policy flags, SECURITY DEFINER count.

Regenerate them after structural changes; they are facts, not prose, and they
go stale silently.
